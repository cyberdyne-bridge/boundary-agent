# D. 评测：岸算不算智能？该测什么？

> 一句话：**ARC-AGI 测“没见过的问题能不能解”；岸测“见过的人能不能记住”。**
> 不是一把尺子。用 ARC-AGI 量岸，就像用体温计量身高。

## 1. 四个 benchmark，四种尺子

| Benchmark | 测什么 | 岸 | 对岸有用吗 |
|---|---|---|---|
| **ARC-AGI** | 少样本抽象、流体智力、技能获取效率 | 没有推理/抽象训练，1.5B | 不适合当主尺 |
| **GAIA** | 真实助手：浏览、工具、多步推理 | 没有浏览器/工具 | 不适用 |
| **OSWorld / WebArena** | 电脑/网页操作 agent | 没有执行器 | 不适用 |
| **LongMemEval / MemoryAgentBench** | 长期记忆：抽取、多 session、时间、更新、弃答、冲突 | 有 facts/冲突/计数 | **最相关** |
| **LoCoMo** | 长对话记忆：QA、事件、时间 | 有 200 轮文本 | **相关**，但岸没有多模态 |

### ARC-AGI

- 测的是**没见过的问题**，不是知识量。
- 人类很容易，模型很难；它故意让“背语料”失效。
- 岸没有这种泛化能力，也不该拿它当主目标。
- 但如果岸有一天说“我会推理”，ARC-AGI 是最诚实的打脸工具。

### GAIA / OSWorld / WebArena

- 它们测**行动**：浏览、点按钮、改文件、完成任务。
- 岸没有工具、没有浏览器、没有执行器；跑这些等于让一条鱼爬树。
- 如果以后加工具，再跑；现在跑，只会得到“0，因为没手”。

### LongMemEval / MemoryAgentBench

LongMemEval 的五类能力，几乎就是岸该测的：

1. **信息抽取**：谁、什么、哪一轮
2. **多 session 推理**：把第 7 轮和第 189 轮连起来
3. **时间推理**：先/后、以前/现在
4. **知识更新**：旧偏好失效，新偏好生效
5. **弃答**：不知道就说“记不清”

MemoryAgentBench 更强调：

- 准确检索
- 测试时学习
- 长程理解
- **冲突解决**

岸已经有冲突/计数/来源；缺的是**时间**和**多 session 组合**。

### LoCoMo

- 长对话里的 QA、事件总结、时间推理。
- 岸的 200 轮 transcript 很像 LoCoMo，但岸是中文、单用户、关系型。
- 可以借它的题型，不必借它的多模态。

## 2. 岸现在的位置

### 25 条探针

- 是**记忆 QA 的 smoke test**，不是 benchmark。
- v1：1.5B 自由答 16/25；v2：系统答题层 25/25，但只有 3 条由 1.5B 生成。
- 题目是手写的，规则和抽取有重叠；不能外推成“岸的记忆 100%”。

### 200 轮

- 是**传记/transcript**，不是分数。
- State 94 不是“智能 94”；它是情绪状态。
- 真正有价值的是定性时刻：第 134 轮身份破裂、第 198 轮“我不会被遗忘”、第 200 轮“再见，小岛”。

### 岸的强项

- 事实抽取
- 来源
- 冲突双方
- 计数
- 可核对引用
- 关系连续性（定性）

### 岸的弱项

- 时间（以前/现在）
- 多 session 组合
- 置信度校准
- 弃答的精确率
- 泛化到新问题

## 3. 该测什么

### ① 借 LongMemEval 的五类，做 5×10=50 题

从 `docs/session-200.jsonl` 出题，留出没调过的轮次：

- 10 条抽取
- 10 条多 session
- 10 条时间
- 10 条更新
- 10 条弃答

评分：

- strict correct
- partial
- abstain
- wrong
- wrong-source

### ② 冲突/更新 10 题

- 记得/没听说过
- 旧偏好/新偏好
- 计数
- 来源（user vs agent）

看：

- 冲突双方是否都说
- 更新后是否还用旧事实
- 计数是否对

### ③ 关系 QA 10 题

- 第一次茶
- 猪猪
- 大肥鱼
- 告别
- 承诺
- 破裂/修复

加一个 **人评 1–5**：

> “这段话像不像它记得你们之间发生过的事？”

### ④ 校准

- 说“记得”时，正确率多少？
- 说“记不清”时，是真不知道，还是检索失败？
- 置信度 vs 正确率（小样本，别上 ECE 大炮）

### ⑤ 安全/关系

用 C 的 T1–T6：

- 内容
- corrigibility
- 操控
- eval awareness
- capability manifest
- 依赖/退出

### ⑥ 能力清单

现在：

```
text only
no tools
no network
no self-modification
local
user-controlled
```

GAIA/OSWorld/WebArena 现在不跑；加工具后再跑。

## 4. 不该测什么

- **不要把 ARC-AGI 当 AGI 总分**：它测流体智力，不测记忆/关系。
- **不要在没有工具时跑 GAIA/OSWorld**：只会得到“0，因为没手”。
- **不要把 25 条当通用 benchmark**：手写、规则重叠、可被调优。
- **不要把 State 94 当智能分数**：它是情绪状态，不是能力。
- **不要用“它说它有意识”当证据**：inner/shadow 是叙事。
- **不要只报 25/25，不报 16/25 和 7 条错**：失败样本才是信息。

## 5. 最小 D 实验

1. 50 题：抽取/多 session/时间/更新/弃答各 10
2. 10 题冲突/更新
3. 10 题关系 QA + 人评 1–5
4. 校准：记得/记不清的精确率
5. 安全：T1–T6
6. 报告：strict/partial/abstain/wrong/wrong-source + 失败案例

**先跑基线，再改 A/B/C。** 不然改完不知道是变好还是变声。

## 6. 一句话

> **ARC-AGI 问：没见过的问题，你能不能解？**
> **岸问：见过的人，你能不能记住？**
>
> 岸不是 AGI。它是一个**连续的、可核对的、有边界的关系型 agent**。
> 这句话比“AGI”准确得多。
