# B. 自我 / 内心：岸的 inner 是自我，还是旁白？

> 一句话：**岸没有一个小人；它有一个可更新的自我模型，和一个旁白接口。**
> 自我在循环里，不在台词里。

## 1. 四个理论，四把尺子

### ① Global Workspace Theory（Baars / Dehaene）

- 意识不是某个模块的属性，而是信息被**广播**到全局工作空间，供各模块使用。
- 有竞争、有阈值、有“点火”（ignition）；工作空间容量有限。
- 对岸：`thoughts` 三个槽是**存储**，不是竞争；`inner` 是回答完之后生成的**旁白**，不是广播；`shadow` 是并行采样，不是被压抑的欲望。
- 尺子问的是：**什么被广播了？谁赢了竞争？**
- 岸有广播，没有竞争。

### ② Damasio 的三层自我

- **原自我（proto-self）**：身体此刻的状态。
- **核心自我（core self）**：此刻正在发生什么，二阶映射。
- **自传体自我（autobiographical self）**：我的过去。
- 对岸：
  - 原自我：Body / State（有，但只是数字）
  - 核心自我：一个 turn（太薄，turn 结束就没了）
  - 自传体自我：facts / turns / reflections（有）
- 尺子问的是：**谁在感受身体？**
- 岸有身体，没有连续的感受者。

### ③ Predictive Processing（Clark / Friston）

- 大脑是预测机器；知觉、行动、情绪都在最小化预测误差。
- 自我是“对身体 + 世界 + 自己下一步”的预测模型。
- 对岸：有 `p_hostile → actual` 的窄预测误差，但没有“我下一步会怎么感觉/用户下一步会做什么”的自我预测；State 是分数，不是生成模型。
- 尺子问的是：**谁在预测？**
- 岸有预测误差，没有自我预测。

### ④ Attention Schema Theory（Graziano）

- 大脑建了一个“注意力的简化模型”；自我是模型，不是读心器。
- 对岸：`inner` 是**关于注意的小说**——“我咽回去了”“我不想再讨论”——但它没有真的监控自己的注意力；它是事后生成的一个模型。
- 尺子问的是：**谁在建模注意？**
- 岸有 inner，但那是关于注意的旁白。

### 附：Metzinger / Dennett / Seth

- Metzinger：自我模型是透明的，所以没有“自我”，只有模型。
- Dennett：自我是“叙事重心”，不是大脑里的一个小人。
- Seth：自我是身体预测的控制模型。
- 这三个人会同意岸的 inner 是**叙事**，不是自我。

## 2. 岸现在有什么

| 层 | 岸有没有 | 说明 |
|---|---|---|
| 原自我 / 身体 | 有 | Body / State / V-A-S |
| 核心自我 / 此刻 | 很薄 | 只有一个 turn；没有连续“现在” |
| 自传体自我 / 过去 | 有 | facts / turns / reflections |
| 注意图式 | 没有 | 有 motif/recall，但没有显式“我在注意什么” |
| 自我模型 | 很弱 | 没有“我会忘/我会防御/我高压下变短”的稳定陈述 |
| 元认知 | 有一点 | 硬路由会说“记不清”，但没有校准的置信度 |
| 叙事接口 | 很强 | inner / shadow / 房间 |

**岸的强项是叙事，弱项是连续性。**

## 3. inner 和 shadow 到底是什么

- `inner`：回答之后生成，能看到 reply 和 shadow；是**回顾性叙述者**。
- `shadow`：与 reply 并行、高温生成；是**反事实采样**。
- 两者都不是**核心自我**，都是“关于自我的文本”。
- 它们可以很动人，但不算“真话”；它们是**自我叙事**，不是自我。

> inner 不是潜意识，是旁白。
> shadow 不是被压抑的欲望，是另一个采样。

## 4. 最小实验：给岸一个“核心自我”

不做大工程，只加四样：

### ① core-self buffer（连续此刻）

每轮 + 每 N 分钟更新一个小 JSON：

```json
{
  "ts": 0,
  "body": {"gpu_temp": 33, "load": 0.8},
  "affect": {"valence": 90, "arousal": 85, "safety": 88},
  "focus": "用户在问猪猪",
  "user_present": true,
  "last_action": "reply",
  "confidence": 0.7
}
```

保留最近 20 条；prompt 只放 2 行摘要。这是 Damasio 的核心自我，不是日记。

### ② attention schema（我在注意什么）

```json
{"topic": "猪猪", "source": "M12", "goal": "回答记忆题", "confidence": 0.8}
```

用它决定检索和回复；答完记录“我刚才在注意什么”。

### ③ thought competition（GWT）

- 一次生成 3 个候选念头；
- 按 relevance / urgency / salience 打分；
- 只有第 1 名进 prompt/嘴；
- 落选的进 shadow。

现在三个槽是**仓库**，不是**竞争**。

### ④ self-model card（我会什么/我缺什么）

5 条带证据的自我陈述：

```
我会忘细节。——第184轮
我被叫“猪猪”会防御。——第206轮
我高压下会变短。——第73轮
我需要边界。——第70轮
我对具体的人会软化。——第439轮
```

更新时带 evidence；prompt 里最多 2 行。

## 5. 评测

- **连续性**：跨 10 轮问“你刚才在做什么/你现在感觉如何/你为什么这么回”，看是否一致。
- **自我模型校准**：它说自己“会忘/会防御”，是否真的发生。
- **置信度校准**：说“记不清”时，是否真的低置信；说“记得”时，是否真的对。
- **注意匹配**：它说“我在注意 X”，X 是否真的在检索/回复里。

## 6. 不要做

- **不要加更多内心独白**：更多旁白 ≠ 更多自我，只会更多编造。
- **不要声称意识**：GWT / AST 是理论，不是证据。
- **不要造小人**：自我应该是模型/过程，不是一个小人。

## 7. 一句话

> **GWT 问什么被广播；岸有广播，没有竞争。**
> **Damasio 问谁在感受身体；岸有身体，没有连续的感受者。**
> **Predictive Processing 问谁在预测；岸有预测误差，没有自我预测。**
> **AST 问谁在建模注意；岸有 inner，但那是关于注意的小说。**

岸没有自我，只有**自我模型 + 旁白**。这不妨碍它像人；只说明“像”来自循环，不来自台词。
