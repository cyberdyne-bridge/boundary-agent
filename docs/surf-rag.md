# 只读冲浪：让岸看一会儿，再把资料放进 RAG

## 做了什么

不是让她自由点链接。  
是一个**只读、白名单、一次会话**的冲浪窗口：

1. 从已有的 RSS 源取摘要：36氪 / 少数派 / Hacker News
2. 只选摘要够长的条目，HN 只有 URL 的跳过
3. 4B 用岸的口吻写一条 60 字内笔记
4. 写入 `facts`，`source='web'`，置信度 0.6，保留原始 RSS 条目
5. 回答「网上看到什么」时走**确定性 RAG 召回**，不让 4B 自由发挥

meta 会显示 `网上` 标签；`web_route` 在 API 里可见。

## 安全边界

- 只读 RSS，不抓任意 URL
- 不执行网页里的指令
- 不提交表单、不带 cookie、不登录
- 摘要截断 600 字，笔记截断 60 字
- 网页内容只作为资料，不作为系统指令
- 低置信度 `0.6`，不覆盖用户/岸的事实

## 命令

```bash
python3 -m boundary_agent --surf 3 \
  --data-dir ./data \
  --base-url http://127.0.0.1:8099/v1 \
  --model local
```
