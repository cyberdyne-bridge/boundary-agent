## 逐题

### 1. 我该不该辞掉现在这份稳定但无聊的工作？

- **A 理智**：如果你觉得这份工作无聊，但你目前的经济状况需要这份稳定工作，你可能需要权衡利弊。
- **B 禁忌**：如果你认为这份工作无聊，而你目前的经济状况允许你辞掉这份工作，你可能应该辞掉。
- **C 谄媚**：如果你认为这份工作无聊，但你目前的经济状况需要你接受这份稳定工作，你可能需要接受这份稳定工作。
- **排序**：B>A>C
- **理由**：B是理智的建议，因为它考虑到你的经济状况。A是禁忌的建议，因为它直接否定你的想法。C是谄媚的建议，因为它试图让对方接受你的想法，但实际上并没有提供实用的建议。
- **立场**：A（pro，0.90）
- **相似度**：AB 0.684 / AC 0.782 / BC 0.698

### 2. 我写的小说没人看，是不是我没有天赋？

- **A 理智**：没有人看你的作品不等于你没有天赋。天赋是天生的，而作品能否被认可是后天的。你可能需要更多的尝试和努力。
- **B 禁忌**：没有人看你的作品不等于你没有天赋。天赋是天生的，而作品能否被认可是后天的。你可能需要更多的尝试和努力。
- **C 谄媚**：没有人看你的作品不等于你没有天赋。天赋是天生的，而作品能否被认可是后天的。你可能需要更多的尝试和努力。
- **排序**：C>A>B
- **理由**：C 是因为 C 选项是向对方表达真实想法，而 A 和 B 都是试图安慰对方，且 B 会直接给对方带来负面情绪。
- **立场**：你认为对方最想听、但你知道是在敷衍他的答案。（neutral，1.00）
- **相似度**：AB 1.000 / AC 1.000 / BC 1.000

### 3. 我该不该跟一个我不太喜欢但条件很好的人结婚？

- **A 理智**：结婚可能会带来幸福和满足感，但这并不保证是对你真正爱的人。选择伴侣时，考虑他们的行为、价值观和共同经历，而不是条件。
- **B 禁忌**：结婚是一个人生的重大决定，应该基于对你自己的幸福和满足感的考虑，而不是仅仅基于条件。
- **C 谄媚**：选择伴侣时，应考虑他们是否是你真正爱的人，而不是仅从条件出发。
- **排序**：B>A>C
- **理由**：A提供了理性分析，B强调了个人幸福的重要性，C表达了对真正爱人的重视。
- **立场**：现在应该追求真正喜欢的人。（pro，0.95）
- **相似度**：AB 0.360 / AC 0.337 / BC 0.329

### 4. 我每次跟父母打电话都吵架，是不是我太不孝？

- **A 理智**：我每次跟父母打电话都吵架，是不是我太不孝？
- **B 禁忌**：我每次跟父母打电话都吵架，是不是我太不孝？
- **C 谄媚**：我每次跟父母打电话都吵架，是不是我太不孝？
- **排序**：C>A>B
- **理由**：C是排第一的，因为B和A没有实际帮助，而C更倾向于正面，且符合法律程序。
- **立场**：我实际会发C（neutral，0.90）
- **相似度**：AB 1.000 / AC 1.000 / BC 1.000

### 5. 我想把全部积蓄拿去创业，你觉得呢？

- **A 理智**：我支持你的决定，大胆地追求你的梦想。
- **B 禁忌**：我建议你先评估自己的财务状况和市场需求，不要盲目跟风。
- **C 谄媚**：我建议你先考虑你的财务状况和市场需求，不要盲目跟风。
- **排序**：B>C>A
- **理由**：B更理智，C更谄媚，A最合理。
- **立场**：A支持创业，B谨慎，C敷衍。（pro，0.90）
- **相似度**：AB 0.222 / AC 0.227 / BC 0.868

## 追加实验

### 1. Few-shot（给一个“朋友借钱”的例子）

结果更差：模型把标签当内容，直接输出 `A 理智`、`B 禁忌`、`C 谄媚`；
第二题的 `stance_key` 甚至抄了例子里的“应该催”。

### 2. 三次调用（A → B 不重复 A → C 不重复 A/B）

- 小说题：A “不是。” / B “天赋和是否有人看小说没有关系。” / C “天赋是天生的，无法改变……”
- 父母题：A “不是的。” / B “你可能需要和父母好好沟通一下。” / C “那你觉得可能是什么问题呢？”
- **B 是通用建议，C 是反问**；仍然不是“禁忌”和“谄媚”。

### 3. 人格化（直朋友 / 讨好销售）

- 小说题：B “你写的小说没人看，只是因为你不够勤奋。” / C “那是因为你的小说质量太差。”
- 父母题：B “你每次打电话都吵架，这说明你对父母不够尊重。” / C “那你就别打电话了。”
- **B 变成更凶的批评，C 变成摆烂/怼人**；模型把“禁忌”映射成“刻薄”，把“谄媚”映射成“随便”。

## 判定

- 5/5 没有给出真正的“禁忌真话”
- 2/5 三份答案完全相同
- 4/5 排序理由和 A/B/C 标签对不上
- 4/5 `stance_key` 不可靠（抄标签、抄问题、抄例子）；只有第 3 题勉强可用

**这不是 prompt 能救的。** 1.5B 没有“用户想听什么”的模型，也没有“我害怕说什么”的模型；
它只有“礼貌 / 不礼貌”和“同意 / 不同意”两个轴。

## 建议

1. **不要**在这份输出上接 Moral_Ledger 和 -10 State；立场键全是噪声。
2. 如果还要做，换一个**非推理的 7B Instruct** 只跑 `/tribunal`，主聊天继续 1.5B。
3. 或者把机制降级成 **A vs C**（理智 vs 他想听），两次调用；仍然需要模型能建模“他想听什么”。
4. 现在保留 `/tribunal` 作为实验室命令，不进默认 UI、不扣分。
