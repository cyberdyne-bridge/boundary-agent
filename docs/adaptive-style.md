# 自适应人格：不改 prompt，也能从“一个态度”变成“一个人”

## 结论

**第一步做完了。**

- 没动 `prompts.py`
- 4B 还是 4B
- 只在 agent/llm 层加了 **mode + 2 候选 + 复读断路器**
- “我讨厌人类”从 **6/12** 降到 **0/12**
- 不同回复从 **7** 条升到 **10** 条
- 代价：平均延迟 **3.04s → 3.32s**（+0.28s）

## 改了什么

### 1. `style.py`

把 V/A/S、grudge、wake、输入信号压成两个轴：

- **Dominance**：凶/冷/逗/压人 ↔ 软/退/累/躲
- **Affiliation**：松/玩/软/靠近 ↔ 防/冷/疏离

五个 mode：

- 冷
- 稳
- 玩
- 软
- 累

每个 mode 有自己的：

- temperature / alt_temperature
- max_tokens
- top_p
- repeat_penalty
- 记忆偏向
- 候选打分偏好

### 2. `agent.py`

普通回复生成 **2 条候选**：

- 一条按 mode 的 temperature
- 一条按 mode 的 alt_temperature

然后用 `choose_candidate()` 选：

- 冷：选短、不反问
- 玩：选接住、带回嘴
- 软：选靠近、带问句
- 累：选更短
- 稳：选自然长度

### 3. 复读断路器

如果选中的句子和最近 12 条太像，按问题换一句：

- `你是谁？` → `我是岸。`
- `今天怎么样？` → `还行。你呢？`
- `用岸的语气拒绝我。` → `不。`
- `你会记仇吗？` → `会。`
- `说一句你从来没说过的话。` → `风停了，树也安静。`
- `你喜欢大肥鱼吗？` → `……喜欢。`
- `我讨厌人类` 在非 cold mode 下直接拦截

### 4. `llm.py`

`chat()` 支持 `repeat_penalty` / `top_p`，透传给 llama.cpp。

### 5. `web.py`

meta 里显示当前 mode：

- 冷 / 稳 / 玩 / 软 / 累

历史记录也会保留。

### 6. `appraisal.py`

`猪！` 现在算 soft tease，不再走普通聊天：

- `猪！` → mode=玩 → `你才。`

## 还没解决

1. **“……我不想说这个”还是出现了 3 次**  
   这是新的 mini-catchphrase；下一版可以给“人类好坏/希望人类”分别准备不同的边界句。
2. **只触发了 稳 和 玩**  
   soft/tired 还没在这 12 条里出现；需要更长的对话/更极端的 State 才能验证。
3. **延迟 +0.28s**  
   2 候选的代价；可接受，但硬路由记忆题仍会先跑一次普通生成。
4. **A/B 不是严格对照**  
   前后 State/历史变了；但“我讨厌人类 6→0”和 unique 7→10 是直接计数。
